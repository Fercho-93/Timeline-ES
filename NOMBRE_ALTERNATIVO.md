# Nombre del juego: conflicto detectado y alternativas (A.5.3)

## El problema

Búsqueda en TMview (30/09/2026) para "Continuum": conflicto real en dos frentes.

- **CONTINUUM** — Microsoft Corporation, clase 9 (software), EUIPO, registrada desde 2001. Cubre toda la UE, incluida España.
- **CONTINUUM GAMES** — Continuum Games, Inc., clase 28 (*"board games, tabletop games, memory games, card games, party games, and dice games; educational games..."*), Estados Unidos, registrada. Este es el más grave: mismo sector exacto (juegos de cartas y mesa).

Conclusión: usar "Continuum" tal cual, o variaciones superficiales como "Continuum.game", tiene un riesgo real de conflicto — no es solo un trámite de registro que pueda fallar, es también posible base para un requerimiento si el juego crece. Pendiente de decisión: cambiar el nombre, o consultar a un agente de la propiedad industrial antes de decidir nada.
