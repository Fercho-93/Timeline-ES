# Trazabilidad del contenido

`node scripts/audit-content.mjs --write` genera el catálogo de referencias y un inventario del arte con huellas SHA-256. `source` significa que existe una referencia registrada; no acredita por sí sola que el dato y sus condiciones coincidan. `rightsEvidence: null` identifica la falta de una evidencia de derechos registrada, no una conclusión de infracción.

Quedan 19 cartas de Naturaleza sin fuente cerrada. Deben revisarse prioritariamente las unidades del topo europeo y los valores que mezclan medias, extremos, libertad/cautividad o fases adultas. Se conserva el registro original mientras se contrasta; no se inventan referencias para cerrar la lista. El inventario permite localizar cada ID y archivo. Antes de un lanzamiento educativo/comercial, documentar cada cifra con la población, sexo o condición, unidad, criterio (media, rango o máximo), referencia y fecha de revisión.

Una muestra revisada durante este trabajo ya muestra por qué importa: Animal Diversity Web distingue obreras de verano de reinas y da una duración de semanas, no una longevidad universal de la especie. La carta de longevidad requiere cerrar exactamente el valor de referencia elegido. No se ha presentado esta consulta como validación de todo el catálogo.

Fuentes consultadas para orientar las revisiones: https://animaldiversity.org/accounts/Apis_mellifera/ y https://pmc.ncbi.nlm.nih.gov/articles/PMC6131963/ .

Para el arte, incorporar al inventario: autor o generador, fecha, origen, condiciones aplicables y autorización de uso comercial. Mantener la evidencia fuera de los recursos distribuidos si contiene datos privados. Revisar también tipografías, textos y dependencias. Los PNG de Inventos se han convertido a WebP sin cambiar sus píxeles; sus originales permanecen en el historial de Git.

Las cartas con referencias deben mostrar el mismo criterio que se usa para ordenar. Los datos aproximados no deben presentarse como récords exactos ni compararse como si fueran medidas homogéneas. Las fuentes y los avisos pendientes se revisan editorialmente antes de ampliar la beta; no se considera terminada esta validación por haber creado el inventario.
